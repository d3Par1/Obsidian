## 📄 Практична 1

Встановлення та запуск Ubuntu як середовища для програмування


Мета роботи
Ознайомитися з процесом встановлення та запуску операційної системи Ubuntu Linux і налаштувати базове середовище для програмування мовами C/C++.


Завдання
1. Встановити Ubuntu (dual-boot, WSL або VirtualBox).
2. Запустити операційну систему.
3. Встановити необхідні інструменти для програмування.
4. Створити, скомпілювати та виконати просту програму мовою C.


1. Варіанти встановлення Ubuntu
1.1. Ubuntu поруч із Windows (dual-boot)
Ubuntu встановлюється як окрема операційна система з можливістю вибору під час запуску комп’ютера.
Переваги:
* повноцінне Linux-середовище
* максимальна продуктивність
Недолік:
* потребує перезавантаження ПК


1.2. Ubuntu у Windows через WSL (Windows Subsystem for Linux)
Ubuntu запускається всередині Windows як термінальне середовище.
Встановлення (у PowerShell від імені адміністратора):
wsl --install -d Ubuntu


Запуск:
* меню Start → Ubuntu
Переваги:
* не потребує перезавантаження
* швидкий старт
Обмеження:
* відсутній графічний інтерфейс (за замовчуванням)


1.3. Ubuntu у VirtualBox
Ubuntu працює у віртуальній машині.
Кроки:
1. Встановити VirtualBox
2. Створити нову VM
3. Підключити ISO Ubuntu
4. Встановити систему
Переваги:
* безпечна ізоляція
* зручна для навчання


2. Перший запуск Ubuntu (dual-boot)
Після перезавантаження комп’ютера з’являється меню GRUB, у якому обирається:
* Ubuntu — для роботи в Linux
* Windows Boot Manager — для Windows


3. Початкове налаштування системи
Відкрити термінал (Ctrl + Alt + T) та виконати:
sudo apt update && sudo apt upgrade -y


Встановити драйвери:
sudo ubuntu-drivers autoinstall
sudo reboot




4. Встановлення інструментів для програмування
4.1. Базовий набір
sudo apt install build-essential git -y


Набір включає:
* gcc, g++ — компілятори
* make
* git


5. Виконання першої програми мовою C
5.1. Створення файлу
nano hello.c


#include &lt;stdio.h>


int main() {
    printf("Hello Ubuntu\n");
    return 0;
}


Збереження файлу:
* Ctrl + O → Enter
* Ctrl + X


5.2. Компіляція та запуск
gcc hello.c -o hello
./hello


Очікуваний результат:
Hello Ubuntu




6. Основні команди Linux

Завдання 1.3 
Припустимо, у вас є програма на C, що складається з кількох файлів:

   * input.c

Вам потрібно:
   1. Написати команду компіляції з використанням gcc.
   2. Змінити команду, щоб програма використовувала process1 із /usr/lib.

   4. Додати прапорці для генерації налагоджувальної інформації (-g) і перевірки продуктивності (-O2).
   5. Створити статичну (.a) і динамічну (.so) версії бібліотек process1 і process та перевірити різницю у виконанні.
   * gcc -c input.c output.c
   * gcc main.c input.o output.o -L/usr/lib -lprocess1 -L~/mylibs -lprocess -o my_program
   * Використовуйте Makefile для автоматизації процесу компіляції.
   * Додайте до Makefile ціль clean, яка видаляє .o файли та виконуваний файл.
   * Напишіть CMakeLists.txt для збирання програми за допомогою CMake.
