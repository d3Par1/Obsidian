стилізацію за допомогою CSS (власний стиль + Bootstrap). 
Практичне заняття No2: реалізація інформаційного веб-сайту енергетичного 
об’єкта. 
Реалізація односторінкового  сайту  для  інформаційного порталу  енергетичного  об’єкта 
(підстанція, сонячна електростанція тощо), що містить: заголовок і підзаголовок; опис об’єкта; 
таблицю  параметрів  (наприклад, потужність,  напруга);  зображення;  навігаційне  меню; 
стилізацію за допомогою CSS (власний стиль + Bootstrap). 
Практичне заняття No3: тестування інформаційного веб-сайту енергетичного 
об’єкта. 
Тестування та оформлення звіту з реалізації односторінкового сайту для інформаційного 
порталу  енергетичного  об’єкта  (підстанція,  сонячна  електростанція  тощо),  що  містить: 
заголовок і підзаголовок; опис об’єкта; таблицю параметрів (наприклад, потужність, напруга); 
зображення; навігаційне меню; стилізацію за допомогою CSS (власний стиль + Bootstrap).

1.1. Теоретичний матеріал 
1.1.1. Основи HTML5 
HTML (HyperText Markup Language) – це мова розмітки для створення веб-сторінок. 
Базова структура HTML-документа 
&lt;!DOCTYPE html> 

4 
 
&lt;html lang="uk"> 
&lt;head> 
    &lt;meta charset="UTF-8"> 
    &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"> 
    &lt;title>Назва сторінки&lt;/title> 
    &lt;link rel="stylesheet" href="styles.css"> 
&lt;/head> 
&lt;body> 
    &lt;!-- Контент сторінки --> 
&lt;/body> 
&lt;/html> 
 
1.1.1.2. Основні теги для проекту: 
- &lt;header> - заголовок сторінки 
- &lt;nav> - навігаційне меню 
- &lt;main> - основний контент 
- &lt;section> - логічний розділ 
- &lt;article> - самостійний контент 
- &lt;aside> - додатковий контент 
- &lt;footer> - підвал сторінки 
- &lt;h1>-&lt;h6> - заголовки 
- &lt;p> - параграф 
- &lt;table> - таблиця 
- &lt;img> - зображення 
- &lt;a> - посилання 
- &lt;div> - контейнер 
- &lt;span> - вбудований контейнер 
1.1.2. Основи CSS3 
CSS (Cascading Style Sheets) – це мова стилів для оформлення HTML. 
1.1.2.1. Способи підключення CSS 
1. Зовнішній файл: &lt;link rel="stylesheet" href="style.css"> 
2. Внутрішні стилі: &lt;style>...&lt;/style> в &lt;head> 
3. Вбудовані стилі: style="color: red;" 
1.1.2.2. Селектори 
- .class - клас 
- #id - ідентифікатор 
- element - тег 
- element.class - тег з класом 
- element > child - прямий нащадок 
- element + sibling - сусідній елемент 
1.1.2.3. Box Model 
- margin - зовнішній відступ 
- border - рамка 

5 
 
- padding - внутрішній відступ 
- width/height - розміри 
1.1.2.4. Flexbox для розташування 
display: flex; 
justify-content: center; 
align-items: center; 
flex-direction: row/column; 
1.1.2.5. Grid для складних макетів 
display: grid; 
grid-template-columns: repeat(3, 1fr); 
gap: 20px; 
1.1.3. Bootstrap 5 
Bootstrap – це CSS-фреймворк для швидкої розробки. 
1.1.3.1. Підключення 
&lt;link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" 
rel="stylesheet"> 
1.1.3.2. Сіткова система (Grid System) 
- .container / .container-fluid 
- .row - рядок 
- .col-* - колонки (12-колонкова сітка) 
- .col-sm-*, .col-md-*, .col-lg-* - адаптивні колонки 
1.1.3.3. Корисні класи 
- .mt-3, .mb-3, .p-4 - відступи 
- .text-center, .text-end - вирівнювання тексту 
- .btn, .btn-primary - кнопки 
- .card - картки 
- .navbar - навігація 
- .table - таблиці 
- .img-fluid - адаптивні зображення 
- .bg-primary, .text-white - кольори 
- .d-flex, .justify-content-center - flex 
1.1.3.4. Компоненти: 
- Navbar - навігаційна панель 
- Card - картки контенту 
- Table - таблиці 
- Button - кнопки 
- Alert - сповіщення
