6.1. Теоретичний матеріал 
6.1.1. Основні загрози веб-безпеки 
6.1.1.1. XSS (Cross-Site Scripting) 
Атака, при якій зловмисник впроваджує шкідливий JavaScript код на веб-сторінку. 
Типи XSS: 
- Reflected XSS - код передається через URL; 
- Stored XSS - код зберігається в БД; 
- DOM-based XSS - маніпуляція DOM на клієнті. 
Приклад вразливого коду: 
javascript: 
// НЕБЕЗПЕЧНО! 
app.get('/search', (req, res) => { 
  res.send(`Результати пошуку: ${req.query.q}`); 
}); 
Захист: 
javascript: 
// БЕЗПЕЧНО 
const escapeHtml = require('escape-html'); 
app.get('/search', (req, res) => { 
  res.send(`Результати пошуку: ${escapeHtml(req.query.q)}`); 
});

користувача.

6.1.1.3. SQL Injection 
Впровадження шкідливого SQL коду через вхідні дані. 
Вразливий код: 
javascript: 
// НЕБЕЗПЕЧНО!
