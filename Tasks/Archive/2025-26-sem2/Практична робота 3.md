## 📄 Практична робота 3: Дослідження обмежень ресурсів у середовищі Docker

Практична робота 3: Дослідження обмежень ресурсів у середовищі Docker
Завдання ЗАГАЛЬНЕ ДЛЯ ВСІХ
Завдання 3.1
Запустіть Docker-контейнер і поекспериментуйте з максимальним лімітом ресурсів відкритих файлів. Для цього виконайте команди у вказаному порядку:
$ ulimit -n
$ ulimit -aS | grep "open files"
$ ulimit -aH | grep "open files"
$ ulimit -n 3000
$ ulimit -aS | grep "open files"
$ ulimit -aH | grep "open files"
$ ulimit -n 3001
$ ulimit -n 2000
$ ulimit -n
$ ulimit -aS | grep "open files"
$ ulimit -aH | grep "open files"
$ ulimit -n 3000


Як наступне вправу, повторіть перераховані команди з root-правами.
Завдання 3.2
У Docker-контейнері встановіть утиліту perf(1). Поекспериментуйте з досягненням процесом встановленого ліміту.
Завдання 3.3
Напишіть програму, що імітує кидання шестигранного кубика. Імітуйте кидки, результати записуйте у файл, для якого попередньо встановлено обмеження на його максимальний розмір (max file size). Коректно обробіть ситуацію перевищення ліміту.
Завдання 3.4
Напишіть програму, що імітує лотерею, вибираючи 7 різних цілих чисел у діапазоні від 1 до 49 і ще 6 з 36. Встановіть обмеження на час ЦП (max CPU time) і генеруйте результати вибору чисел (7 із 49, 6 із 36). Обробіть ситуацію, коли ліміт ресурсу вичерпано.
Завдання 3.5
Напишіть програму для копіювання одного іменованого файлу в інший. Імена файлів передаються у вигляді аргументів.
Програма має:
* перевіряти, чи передано два аргументи, інакше виводити "Program need two arguments";
* перевіряти доступність першого файлу для читання, інакше виводити "Cannot open file .... for reading";
* перевіряти доступність другого файлу для запису, інакше виводити "Cannot open file .... for writing";
* обробляти ситуацію перевищення обмеження на розмір файлу.
Завдання 3.6
Напишіть програму, що демонструє використання обмеження (max stack segment size). Підказка: рекурсивна програма активно використовує стек.
Завдання по ВАРІАНТАХ
1. Написати програму, яка створює багато потоків та перевірити вплив ulimit -u.
2. Встановити обмеження на кількість відкритих сокетів (ulimit -n) та запустити серверну програму.
3. Написати програму, яка використовує багато пам'яті та перевірити обмеження (ulimit -v).
4. Реалізувати програму, що перевіряє максимальну кількість запущених процесів (ulimit -u).
5. Встановити ліміт на використання CPU (ulimit -t) і запустити нескінченний цикл.
6. Дослідити вплив ulimit -l на фіксовану пам’ять (locked memory).
7. Використати ulimit -v для обмеження використання резидентної пам’яті.
8. Написати програму, що генерує велику кількість дескрипторів файлів.
9. Використати ulimit -d для обмеження динамічної пам’яті процесу.
10. Написати сценарій, що тестує всі ulimit обмеження в одному виконанні.
11. Дослідити вплив ulimit -s на роботу рекурсивних алгоритмів.
12. Написати програму, що читає багато малих файлів одночасно, та перевірити обмеження.
13. Дослідити зміну обмежень ресурсів через /etc/security/limits.conf.
14. Запустити контейнер з різними значеннями ulimit та порівняти поведінку програм.
15. Дослідити вплив ulimit -f на роботу програми, що пише великі файли.
16. Використати ulimit -a для збору всіх поточних обмежень та автоматично тестувати їх.
17. Написати програму, що використовує спільну пам’ять (shmget) та перевірити ulimit -l.
18. Написати багатопотокову програму, яка перевіряє вплив ulimit -u.
19. Створити імітацію серверного навантаження і протестувати обмеження.
20. Написати програму, яка тестує вплив ulimit -r на пріоритети процесів.
21. Дослідити взаємодію ulimit та cgroups у Docker.
22. Використати ulimit -x для перевірки ліміту на виконувані файли.
23. Написати програму, яка тестує різні методи обмеження ресурсів у Linux.
24. Виконати масштабне тестування різних значень ulimit на серверному середовищі.
25. Реалізувати систему моніторингу використання ulimit у режимі реального часу.
